Project 6: Unidirectional Data Flow and Declarative UI

Unidirectional Data Flow (UDF)

UDF is a pattern where state flows down and events flow up. This makes UI updates predictable and easy to debug.

graph TD VM[ViewModel] -- "uiState (Flow)" --> UI[Screen/Composable] UI -- "Click Event" --> VM VM -- "Logic Update" --> VM

Jetpack Compose

Compose is a declarative UI toolkit. You describe WHAT the UI should look like for a given state, and Compose handles the HOW.

@Composable
fun VibeScreen(state: VibeState) {
    Text("Count: ${state.count}")
    Button(onClick = { /* send event */ }) {
        Text("Increment")
    }
}

State Management

MutableStateFlow

A state-holder observable flow that emits the current and new state updates to its collectors.

collectAsState()

A Compose extension that transforms a Kotlin Flow into a Compose State, triggering recomposition on changes.

Recomposition

The process of calling your Composable functions again with new data when the state changes.
