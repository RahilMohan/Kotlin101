Project 5: Regular Expressions and Data Processing Pipelines

Regex: Pattern Matching Power

Regular Expressions (Regex) allow us to define complex search patterns for strings. We use them here to decompose semi-structured log lines into structured data objects. 

val regex = Regex("""\[(.*)\]\s+(INFO|WARN|ERROR):\s+(.*)""")
graph LR Line["[2026-05-26] ERROR: Crash"] -- "Regex Match" --> S["Structured Data"] S --> T["Timestamp: 2026-05-26"] S --> L["Level: ERROR"] S --> M["Message: Crash"]

The Processing Pipeline & Channels

We use Kotlin Flow to create a streaming pipeline that reads and parses data lazily. We then use a Channel to decouple the parsing logic from the aggregation logic, allowing for concurrent processing.

graph LR F[File] --> L[Lines: Flow<String>] L --> P[Parser: Flow<LogEntry>] P -- "channel.send()" --> C[Channel] C -- "for(entry in channel)" --> A[Aggregator: Map<String, Int>] A --> T[Terminal Table]

Lazy Evaluation

Flows are cold—processing only happens when collect is called, minimizing memory footprint for large files.

Using functional patterns to aggregate statistics without complex nested loops.
