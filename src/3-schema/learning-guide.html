Kotlin Reflection (KReflect)

Reflection allows a program to inspect its own structure at runtime. In this project, we use it to iterate over properties of a class and determine their types without knowing them at compile time.

Generics & Reified Types

Kotlin's reified parameters allow us to access the type information of a generic parameter at runtime, which is normally erased in Java.

inline fun <reified T : Any> generate(): String {
    return generateForClass(T::class)
}

The inline keyword combined with reified tells the compiler to copy the function body to the call site, keeping the specific type T accessible.
