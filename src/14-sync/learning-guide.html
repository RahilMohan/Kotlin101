Project 14: Data Layer Synchronization and Conflict Resolution

The Data Layer API

Wear OS devices often need to stay in sync with a paired phone. The Data Layer API provides a replicated data store where changes on one device are automatically propagated to the other.

graph LR P[Phone App] -- "DataItem Update" --> G[Google Play Services] G -- "Bluetooth/Cloud" --> S[Wear OS Device] S -- "OnDataChanged" --> W[Watch App]

Conflict Resolution

When two devices update the same data simultaneously, a conflict occurs. We must decide which update to keep. Common strategies include Last-Writer-Wins (LWW) and Version Merging.

Payload Serialization

SyncPacket

A structured wrapper for data that includes metadata like version and timestamp for reliable synchronization.

Byte Conversion

The Data Layer API transfers raw byte arrays. We use Kotlin Serialization to encode/decode our packets to/from JSON strings or Protobuf.

Idempotency

Ensuring that receiving the same sync packet multiple times doesn't cause incorrect state updates.
