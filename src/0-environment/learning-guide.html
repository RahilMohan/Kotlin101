Project 0: Laying the Foundations for Wear OS Development

The Toolchain

A professional Kotlin environment requires a synchronized stack of runtimes, compilers, and SDKs. For Wear OS 4, we target API 33/34.

JDK 25

The latest Java Runtime providing the underlying VM for Kotlin execution.

Kotlin 2.3

Featuring the K2 compiler for faster builds and improved type inference.

Android SDK

Platform 33 (Tiramisu) and 34 (Upside Down Cake) for Wear OS 4+ compatibility.

Connectivity: ADB Over Wi-Fi

Wearable devices are often small and lack physical ports. ADB (Android Debug Bridge) over Wi-Fi allows for untethered, high-speed deployment.

graph LR A[Developer Machine] -- "adb connect" --> B((Wi-Fi Router)) B -- "TCP/IP" --> C[Wear OS Watch] subgraph "Wireless Link" C end

This setup uses adb pair for initial security and adb connect for subsequent sessions, bypassing the need for USB cables.

The Developer Workflow

Debugger Shortcuts

F8 (Over), F7 (Into), and F9 (Resume) are the primary navigation keys for inspecting state.
