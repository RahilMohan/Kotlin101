Bi-directional Communication

Unlike standard HTTP requests (Client -> Server), WebSockets allow the server to push data to the client at any time (Server -> Client). This is essential for chat apps.

sequenceDiagram participant C as Client (Compose UI) participant S as Server (WebSocket) C->>S: Handshake (HTTP Upgrade) Note over C,S: Persistent Connection Established C->>S: Message: "Hello!" Note over S: Process message S-->>C: Broadcast: "Hello!" (to all clients) S-->>C: Event: "User B is typing..."

Advanced Serialization

In a real-time app, we often send polymorphic data (different types of messages over the same stream). kotlinx.serialization handles this using class discriminators.

@Serializable
sealed class ChatEvent {
    @Serializable
    data class Message(val text: String) : ChatEvent()
    @Serializable
    object Typing : ChatEvent()
}
