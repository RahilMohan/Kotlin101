The Watch Face Lifecycle

A watch face is a specialized service. It has two main modes: Active (high refresh rate, colors) and Ambient (low power, Always-On, minimal pixels).

Clock Trigonometry

To draw clock hands, we must convert time into angles and then into X/Y coordinates using Sine and Cosine functions.

// Angle for seconds
val angle = (second * 6 * (PI / 180) - PI / 2)
// Offset calculation
val x = cos(angle) * length
val y = sin(angle) * length

Subtracting PI/2 (90 degrees) is necessary because the unit circle starts at 3 o'clock, but clocks start at 12.
