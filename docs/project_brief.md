# Project Brief: Kotlin & Wear OS Mastery

## Problem
Developing for Wear OS and modern Android requires a deep understanding of Kotlin's specific paradigms (Null Safety, Coroutines, Flow) and the Android Jetpack ecosystem. Transitioning from JS/Python often leads to "Type-system friction."

## Users
- Primary: Engineering Student (Experienced in JS/Python).
- AI Agent: Gemini CLI (Mentor and Implementation partner).

## Scope
A 16-project curriculum (0-15) moving from CLI fundamentals to specialized Wear OS system APIs.

## Non-Goals
- Building full production startups for each project.
- Deep diving into iOS development.
- Legacy Android (Java-based) patterns.

## Success Criteria
- Completion of 16 functional projects.
- Mastery of Jetpack Compose for both Mobile and Wearable.
- Proficient use of Wear OS sensors, Tiles, and Complications.
- Creation of interactive HTML learning guides for each project explaining core concepts.
